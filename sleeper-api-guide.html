Sleeper League API Guide

Yes, Sleeper has a public API. You can pull your league's current season and every past season with plain HTTP GET requests. No account, API key, or login is needed.

Freefor non-commercial use
No authread-only, no token
<1000/minstay under this or risk an IP block
JSONevery response

Base URL: https://api.sleeper.app/v1 · Official docs: docs.sleeper.com

How the data fits together

Five IDs connect everything. Once you have these straight, the rest is joining tables.

user_id

A person. Look it up from your username. Stays the same forever.

league_id

One league for one season. Sleeper creates a new league_id every time a league renews.

previous_league_id

Field on each league that points to last season's league_id. Follow it to walk back through history.

roster_id

A team slot in a league (1, 2, 3…). Matchups and transactions use this, not user_id. Rosters map it to an owner_id.

player_id

A player, like "4046". Team defenses use the team code, like "CAR". Translate with the players file.

matchup_id

In a week's matchups, the two rosters sharing a matchup_id played each other.

All are GET requests on the base URL. Use nfl for sport.

Steps to pull your league

You can paste each URL into a browser to see the JSON. Swap in your own values where you see braces.

  1. Get your user_id from your username

    Your username is the handle shown in the Sleeper app (not your email).

    curl https://api.sleeper.app/v1/user/YOUR_USERNAME

    Copy user_id from the response.

  2. Check the current season and week

    curl https://api.sleeper.app/v1/state/nfl

    When I called it today it returned "season": "2026" and "week": 4.

  3. Find your league_id for this season

    curl https://api.sleeper.app/v1/user/{user_id}/leagues/nfl/2026

    Pick your league by name and copy its league_id. It's also in the app's web URL: sleeper.com/leagues/{league_id}/…

  4. Pull the members and the rosters, then join them

    curl https://api.sleeper.app/v1/league/{league_id}/users
curl https://api.sleeper.app/v1/league/{league_id}/rosters

    Match rosters[].owner_id to users[].user_id. Now each roster_id has a name. Standings live in rosters[].settings: wins, losses, ties, fpts, fpts_decimal, fpts_against.

  5. Pull weekly matchups

    curl https://api.sleeper.app/v1/league/{league_id}/matchups/1

    Loop week 1 through the current week. Group results by matchup_id to get head-to-head pairs. Each entry has points, starters, and players_points.

  6. Pull transactions, playoffs, and the draft

    curl https://api.sleeper.app/v1/league/{league_id}/transactions/1
curl https://api.sleeper.app/v1/league/{league_id}/winners_bracket
curl https://api.sleeper.app/v1/league/{league_id}/drafts
curl https://api.sleeper.app/v1/draft/{draft_id}/picks

    The number on transactions is the week (Sleeper calls it a "round" or "leg"). Each transaction has a type: trade, waiver, or free_agent.

  7. Walk back through past seasons

    Read previous_league_id from the league object and repeat steps 4 to 6 with it. Stop when it is null or "0".

    2026league_id
    previous_league_id →
    2025league_id
    previous_league_id →
    2024league_id
    → … until null

    For a past season, the final regular-season week is settings.playoff_week_start − 1 on the league object. Playoff weeks follow it.

  8. Translate player IDs into names

    curl -o players.json https://api.sleeper.app/v1/players/nfl

    Save it to a file and look up names locally. Don't call this inside a loop.

Starter script

Python, standard library only. Set your username and league name, run it, and it saves every season of your league to a sleeper_data/ folder.

import json, os, time, urllib.request

USERNAME = "your_sleeper_username"
LEAGUE_NAME = "Your League Name"   # as shown in the app
BASE = "https://api.sleeper.app/v1"
OUT = "sleeper_data"

def get(path):
    with urllib.request.urlopen(f"{BASE}{path}") as r:
        time.sleep(0.1)            # stay far under 1000 calls/minute
        return json.load(r)

def save(name, data):
    os.makedirs(OUT, exist_ok=True)
    with open(os.path.join(OUT, name), "w") as f:
        json.dump(data, f, indent=2)

user = get(f"/user/{USERNAME}")
state = get("/state/nfl")
season = state["season"]

leagues = get(f"/user/{user['user_id']}/leagues/nfl/{season}")
league_id = next(l["league_id"] for l in leagues if l["name"] == LEAGUE_NAME)

while league_id and league_id != "0":
    league = get(f"/league/{league_id}")
    yr = league["season"]
    print(f"Pulling {yr}: {league['name']}")

    # last week with games: current week this season, full season for past years
    if yr == state["season"]:
        last_week = state["week"]
    else:
        last_week = league["settings"].get("playoff_week_start", 15) + 2

    data = {
        "league": league,
        "users": get(f"/league/{league_id}/users"),
        "rosters": get(f"/league/{league_id}/rosters"),
        "matchups": {w: get(f"/league/{league_id}/matchups/{w}") for w in range(1, last_week + 1)},
        "transactions": {w: get(f"/league/{league_id}/transactions/{w}") for w in range(1, last_week + 1)},
        "winners_bracket": get(f"/league/{league_id}/winners_bracket"),
        "losers_bracket": get(f"/league/{league_id}/losers_bracket"),
        "drafts": get(f"/league/{league_id}/drafts"),
    }
    data["draft_picks"] = {d["draft_id"]: get(f"/draft/{d['draft_id']}/picks") for d in data["drafts"]}
    save(f"{yr}.json", data)

    league_id = league.get("previous_league_id")

if not os.path.exists(os.path.join(OUT, "players.json")):
    save("players.json", get("/players/nfl"))   # ~5 MB, once
print("Done.")

Things to know

  • Read-only. You can't set lineups, make trades, or change anything through the API.
  • History only goes as far back as your league does on Sleeper. If the league moved from ESPN or Yahoo, seasons before the move aren't there.
  • A broken chain is possible. If a commissioner made a brand-new league instead of renewing, previous_league_id won't link them. Use step 3 with the older season number to find the old league_id.
  • Points come in two parts on rosters: fpts (whole number) and fpts_decimal. Add them: fpts + fpts_decimal / 100.
  • No official stats or projections endpoint. People reference undocumented ones online. They can change without notice, so I'd avoid relying on them.
  • Commercial use needs a license. Personal projects and league tools are fine under the free terms.
  • A docs typo: one heading says loses_bracket. The working path is losers_bracket.

Sources: Sleeper's official API docs at docs.sleeper.com, and live calls to /state/nfl and /players/nfl/trending/add on October 4, 2026, which both returned data with no authentication.
